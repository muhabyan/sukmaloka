# Sukmaloka

*perihal berat sebuah jiwa* — sebuah buku tua di meja steampunk, dengan teater kertas di setiap halaman.

Situs statis: cukup HTML, JavaScript, gambar, dan suara. Tidak butuh server, database, atau build step.

## Menjalankan di komputer

```
python -m http.server 8000
```
lalu buka http://localhost:8000

## Deploy ke Vercel

1. Unggah isi folder ini ke repository GitHub baru.
2. Di vercel.com: Add New → Project → pilih repository itu.
3. Framework Preset: **Other**. Build Command dan Output Directory dikosongkan.
4. Deploy.
